# Mamdouh Alsaudi — Personal Portfolio Website

My personal portfolio website — pure HTML/CSS (no build step), trilingual (EN / AR / PT), navy & gold identity.

**Live:** https://mamdouhalsaudi.netlify.app

## Pages
- `index.html` — English (default)
- `ar.html` — العربية (RTL)
- `pt.html` — Português
- `404.html` — custom not-found page

## Features
- Fixed nav with language switcher + contact icons (GitHub / LinkedIn / Email)
- Infinite auto-scrolling projects rail (pauses on hover)
- Gold-bordered skill chips (incl. AI tools) and language progress bars
- Real project screenshots in `img/`
- SEO + Open Graph/Twitter cards (`img/og-card.png`)
- Responsive: phone / tablet / desktop + print stylesheet
